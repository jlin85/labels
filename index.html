Spreadsheet import

For lists with several columns. Paste rows from Excel or Google Sheets, or load a CSV, with column names in the first row. Put {ColumnName} in any text, QR code or barcode, and one label prints per row. For a plain list of names, use Names, blanks & numbering instead.
